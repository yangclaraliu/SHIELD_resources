## Layout

Four floating island layers stacked vertically, each a rounded oval/pill shape.
Each layer is incrementally smaller in width from bottom to top, creating a pyramid effect.
The size difference between layers must be dramatic and clearly visible — DATA should be at least 2–3x wider than DECISIONS, with each layer showing a significant step down in width, not a subtle gradient.

Each layer has:
  - A rounded rectangular callout box on the LEFT, same size across all four layers, connected to the island by an arrow pointing right.
    Callout box style: very light warm gray (#F5F5F5) background, dark text.
    Each callout box has a single large icon in the top-left corner and 3 bullet points of text. Icons and text are top-aligned. Bullet point icons are vertically aligned in a strict column.
  - A rounded rectangular player label box floating to the RIGHT, vertically aligned with its island. No connecting arrow or line.
    Player label box style: white background, thin border matching the island colour.
